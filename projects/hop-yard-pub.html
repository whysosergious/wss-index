Craft beer pub · Södermalm, Stockholm

Twelve taps, zero surprises

A Södermalm taproom where the menu always tells the truth: live keg levels, automatic reorders, and Untappd ratings that update themselves.

There is a special kind of embarrassment in pouring a guest a beer, watching the tap sputter, and then reading the chalkboard behind you that still promises it. The Hop Yard had twelve taps and a chalkboard that lied every Friday. Staff lifted kegs in the cold room to guess what was left — a method with a long tradition and zero accuracy. My brief was simple: never let a guest order a beer that doesn't exist.

What I built is a nervous system for the bar. Cheap flow-meter pulses become litres remaining per keg. The TV menu, the website and the staff tablet all read one live tap list. Under five litres, the bar gets a reorder nudge; at zero, the tap flips to "kicked" everywhere instantly. Untappd scores sync overnight so the menu carries ratings without anyone typing them in.

The goal

Real-time keg tracking with honest levels, inventory automation that reorders before a tap dies mid-service, Untappd integration, and a customer-facing menu that can never show a kicked keg. It had to survive a Friday night with sticky fingers on the tablet and no patience for "the system is syncing".

What kept me up at night

First, cheap sensors lie. Flow-meter pulses drift with temperature, foam and line pressure, and every line flush during cleaning looks like a massive pour. Raw pulses would have shown fantasy numbers within a week. So each tap got its own calibration constant, and anything flagged as a cleaning flush is excluded from the maths entirely. Honest litres or nothing.

Second, the menu must never disagree with reality. A TV showing a dead beer is the original sin this whole project exists to kill. One query powers every screen, kicked kegs are filtered at the database — not in the frontend, where someone will forget — and status changes push out live instead of waiting for a refresh.

Third, Untappd's rate limits. You can't hammer their API from a bar with hundreds of beers; you get throttled and the whole sync dies. The sync runs nightly, one request per second-ish, caches everything, and any failure just queues a retry. Boring, resilient, invisible.

The piece of code that saved us

The keg-level module. It turns raw pulses into a status the whole bar understands — pouring, low, kicked — with per-tap calibration, cleaning exclusions, and a reorder nudge exactly once when a keg crosses into "low". Everything downstream, from the TV menu to the supplier email, keys off this one function.

// keg-meter.ts — pulses in, truth out. Calibrated per tap.
export interface Keg {
  id: string; beerName: string;
  capacityMl: number; remainingMl: number;
  mlPerPulse: number; // calibrated: foam and pressure differ per line
  status: 'pouring' | 'low' | 'kicked';
  reorderSent: boolean;
}

const LOW_THRESHOLD_ML = 5000; // roughly the last honest evening

export function applyPulses(keg: Keg, pulses: number, ctx: { cleaning: boolean }) {
  if (ctx.cleaning) return keg; // line flushes are not pours
  if (pulses < 0) throw new Error('Negative pulses: check the meter wiring');

  keg.remainingMl = Math.max(0, keg.remainingMl - pulses * keg.mlPerPulse);

  const was = keg.status;
  keg.status = keg.remainingMl <= 0 ? 'kicked'
    : keg.remainingMl < LOW_THRESHOLD_ML ? 'low' : 'pouring';

  // Nudge the supplier exactly once per keg — no spam, no silence.
  if (keg.status === 'low' && was === 'pouring' && !keg.reorderSent) {
    queueReorder(keg); // supplier email + staff tablet ping
    keg.reorderSent = true;
  }
  if (keg.status === 'kicked') pushTapUpdate(keg); // every screen, now

  return keg;
}

The was === 'pouring' transition check is the whole trick: the nudge fires on the crossing, not on the level, so a meter that flutters around the threshold can't spam the supplier.

How it landed

No more mid-service dry taps — reorders now happen while there's still an evening left in the keg. Beer waste dropped by about a third because "lift the keg and guess" retired. And the chalkboard? It still exists, actually. It just says things like "ask what's new" now, because the TV handles the truth.

What I'd do differently

I'd log temperature next to every pulse from the start. Twice we chased "drunk meter" ghosts that turned out to be a warm cold-room making foam — data we could have had for the price of a sensor.
