Stretch ceilings · Minsk, Belarus · 2021 · 5 min read

The 60-second quote

A Minsk ceiling company where clients price their own renovation in a minute — and crews, materials and invoices stopped living in phone calls.

By Sergio Stankevich · Freelance full-stack build

Selling stretch ceilings in Minsk worked like this: a client calls, someone drives out, measures with a laser, goes back to the office, builds the quote in Excel, calls back two days later. Two office staff did little else but re-type orders, and every forgotten spotlight cut-out meant wasted canvas and an awkward conversation. The owner — a practical man with sawdust permanently in his van — asked me the same question everyone asks: "can the website just... tell them the price?"

It could, but only if the price was honest. A ceiling quote isn't one number; it's canvas by square metre, profile, corners beyond the standard four, every spotlight, every chandelier mount, plus the crew day it all takes. I spent a day with an estimator learning how he thinks, then taught the website to think the same way — line by line, explainable, matching the final invoice to the rouble.

The goal

A client-facing configurator that prices a ceiling in about a minute, books the crew, and follows the job with progress photos to the client portal. Behind it: materials and stock, crew scheduling that can't double-book, and invoices that write themselves from the approved quote. No more Excel, no more phone Tetris.

What kept me up at night

First, trust in the number. A quote the client doesn't believe is worse than no quote — it poisons the sale. So the engine shows every line, uses the same rates the estimator uses, and the PDF quote, the portal and the invoice all render from the same function. One formula, three outputs, zero drift.

Second, double-booked crews. Two jobs, one crew, one Monday morning — the classic. I didn't build a calendar with warnings; I built a database constraint that makes overlaps impossible. The app can have bugs; the data can't be wrong. The crew day estimate also comes from the spec, so scheduling starts from the quote instead of a guess.

Third, the forgotten cut-out. Spots and chandeliers are where margins die, because canvas gets cut and can't be uncut. The configurator forces the count up front with plain questions ("how many spotlights?"), prices each one, and the warehouse picks the job from the same spec. Surprises dropped to nearly zero.

"The app can have bugs; the data can't be wrong. Overlaps are impossible at the database level, not just discouraged in the UI."

The piece of code that saved us

The pricing engine, with the crew-day estimate attached. It prices the canvas, the extra corners, every light point — and then converts the spec into installer hours so scheduling starts from facts. The client sees the quote, the crew sees the day plan, the invoice sees the same lines. This function is the business.

// ceiling-pricing.ts — the estimator, as code. One formula, three outputs.
export interface CeilingSpec {
  areaM2: number; corners: number;
  spots: number; chandeliers: number;
  canvas: 'matte' | 'gloss' | 'fabric';
  twoLevels: boolean;
}

const RATES = {
  canvas: { matte: 32, gloss: 38, fabric: 55 }, // per m², BYN
  corner: 6, spot: 9, chandelier: 18, level: 45, // per unit / per m²
};

export function priceCeiling(s: CeilingSpec) {
  const lines = [
    { label: `Canvas ${s.canvas} × ${s.areaM2} m²`, sum: s.areaM2 * RATES.canvas[s.canvas] },
    { label: `Extra corners × ${Math.max(0, s.corners - 4)}`, sum: Math.max(0, s.corners - 4) * RATES.corner },
    { label: `Spotlights × ${s.spots}`, sum: s.spots * RATES.spot },
    { label: `Chandeliers × ${s.chandeliers}`, sum: s.chandeliers * RATES.chandelier },
  ];
  if (s.twoLevels) lines.push({ label: `Second level × ${s.areaM2} m²`, sum: s.areaM2 * RATES.level });

  const total = lines.reduce((a, l) => a + l.sum, 0);

  // Installer time from the same spec — scheduling starts from facts.
  const hours = 2 + s.areaM2 * 0.25 + s.spots * 0.3 + s.chandeliers * 0.8
    + (s.twoLevels ? s.areaM2 * 0.4 : 0);

  return { lines, total: Math.round(total), crewHours: Math.round(hours * 10) / 10 };
}

Pair this with the exclusion constraint on crew bookings — a crew simply cannot hold two jobs at once, no matter what the UI does — and the Monday-morning phone chaos just... stopped.

How it landed

Clients quote themselves in about a minute now, and they arrive pre-sold — the quote taught them what things cost, so the sales call is short. Office re-typing dropped by roughly two thirds. Crews haven't been double-booked once since launch, and the estimator? He still drives out for the tricky ones. But now he brings a printed quote the website already made, and signs it on the spot.

What I'd do differently

I'd photograph every finished ceiling into a gallery tied to the spec that built it. "Show me gloss ceilings around 18 m²" would sell more than any configurator — social proof, priced.
